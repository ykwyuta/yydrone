# チュートリアルモード

タイトルで陣営を選び、「チュートリアル」を押すと専用訓練場に入ります。Windows版・ブラウザ版の共通機能です。観戦が選ばれている場合はウクラヴィア側で始まります。

## 進め方

左上のガイドに目標と操作方法が表示されます。実際の操作で目標を達成すると「次へ」が有効になります。

| 課題 | 達成条件 |
|---|---|
| 1 戦場を見渡す | カメラの移動と拡大・縮小 |
| 2 部隊を選ぶ | 指定歩兵を選択 |
| 3 移動を命じる | 歩兵が目標地点へ到着 |
| 4 拠点を制圧する | 訓練拠点の支配が自軍に変わる |
| 5 敵を攻撃する | 訓練用IFVを撃破 |
| 6 部隊を生産する | 新しい歩兵の生産が完了 |
| 7 補給所を建設する | 新しい補給所の建設が完了 |
| 8 偵察ドローンを生産する | 新しい偵察機の生産が完了 |
| 9 偵察する | 指定偵察機が偵察地点へ到着 |
| 10 FPVで車両を攻撃する | FPV班が実際にFPVを発進し、敵戦車を撃破 |
| 11 将軍に指揮を委任する | 部隊・100以上の予算・訓練場を含む地域を委任し、全力防御を指示 |
| 12 参謀の助言を読む | 参謀本部の「助言と戦力案」を開く |
| 13 戦線レポートを読む | 初回報告が届いた後に「戦線レポート」を開く |

「目標へ」で目印のある場所を映せます。選択による指揮中の停止や一時停止は「選択解除・再開」で解消できます。生産・建設・制圧には通常と同じ時間が必要で、×4などの速度変更も使えます。司令部を開いている間は時間が止まるため、報告を待つ際は一度閉じてください。訓練の初回報告だけ約8秒で届きます。

「やり直す」は現在の課題の初期状態に戻します。「スキップ」は未達成の課題も飛ばせます。次の課題へ進む際は必要な部隊・施設を準備した状態から始まるので、前の課題の失敗や飛ばした操作に影響されません。最後に達成数とスキップ数が表示され、通常作戦・再練習・タイトルを選べます。

## 通常戦との分離

訓練中は敵の自動増援、史実イベント、天候変化、時間切れによる終了が発生しません。敵の標的は反撃しません。生産・移動・視界・制圧・戦闘・建設・将軍の指揮と報告は本体の処理を使います。

訓練中の手動保存・自動保存・アプリ中断時の保存は行いません。既存の保存枠は保護され、記録画面にも専用の説明が表示されます。訓練の途中経過は保存されず、終了するとタイトルへ戻ります。通常作戦を開始すると通常の保存機能に戻ります。

## 検証

`cargo test -p yydrone-core -p yydrone-game --lib -- --skip long_sim_finishes_with_winner`

両陣営で13課題の未達成時の進行制限と実際のシミュレーションによる達成を検証します。保存の遮断、課題切替時の初期化、通常セーブの読み込み・通常作戦への移行も確認します。

ブラウザの操作テストは `node tools/verify_command_ui.mjs <chrome.exeのパス> --tutorial`。隔離したプロファイルとローカルサーバーで実行し、デスクトップの全課題、1000×480の選択・やり直し・スキップ・終了、通常作戦への移行を確認します。`dist/` は事前に最新のWASMに更新してください。
