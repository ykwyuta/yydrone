# 史実イベントの年表と出典

ゲームの出来事（[crates/core/src/history.rs](../crates/core/src/history.rs)）は、実際の戦争の出来事を日付どおりに起こします。
ゲーム内の国名・地名・人名・兵器名は少し変えた架空の名前で、下の表で実際の名前と対応させています。ゲームとしての効果（増援の数など）は創作です。

## 暦

2時間の試合の中で 2022年2月24日から2026年10月31日までが流れます。動きの多い時期を長く遊べるよう、時間の進み方は一定ではありません。

| 経過時間 | 暦 |
|---|---|
| 0〜14分 | 開戦〜キエフ州の解放（2022年4月2日） |
| 14〜46分 | 2022年の残り |
| 46〜66分 | 2023年 |
| 66〜84分 | 2024年 |
| 84〜101分 | 2025年 |
| 101〜116分 | 2026年1月〜10月14日 |
| 116〜120分 | 2026年10月14日〜31日 |

## 史実と盤面が離れたとき

「マリウポラ陥落」など、特定の都市を持っていることが条件の出来事は、条件を満たさなければ効果が出ず、「この戦争では起きなかった」と記録されます。
撤退や奪還の出来事は AI に委任された部隊だけを動かし、プレイヤーが直接指揮している部隊とその周辺の領土は動かしません。

キエヴァ攻防戦の間（2022年4月2日まで）は、AI のロスコヴィア軍はキエヴァの半径13タイルの内側へ進みません。プレイヤーがロスコヴィアを指揮する場合は、守備側の被害軽減を破れば進めます。
